# Madhav E-commerce Sales Dashboard | Power BI

## 📊 Project Overview

This project is an interactive E-commerce Sales Dashboard created using Microsoft Power BI.

The dashboard analyzes sales and profit performance using order and order-detail data.

## 📁 Dataset

The project uses two datasets:

- Orders.csv
- Details.csv

The datasets contain information related to orders, sales, profit, quantity, customers, states, categories, sub-categories and payment modes.

## 📈 Dashboard Features

- Total Sales Amount
- Total Profit
- Total Quantity
- Sales by Month
- Sales by State
- Profit by Payment Mode
- Profit by Category
- Profit by Sub-Category
- Sales by Customer
- Interactive Order Date filter
- Interactive State filter

## 🛠️ Tools Used

- Microsoft Power BI
- Data Cleaning
- Data Transformation
- Data Visualization
- Data Analysis
